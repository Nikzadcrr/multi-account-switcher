# راهنمای اتصال «جیمیل من (الیاس)» — نسخهٔ ۳.۵

با این قابلیت، آدرس‌هایی مثل `you+netflix@gmail.com` روی **جیمیل واقعی خودت** می‌سازی.
دامنه‌ی gmail.com واقعی است، پس **هیچ سایتی آن را رد نمی‌کند** و نیازی به خرید دامنه یا ساخت اکانت جدید نیست.

---

## ⚡ روش جدید — اتصال فوری (بدون هیچ تنظیمی)

از نسخهٔ ۳.۵ می‌توانی کلاً از مراحل Client ID رد شوی:

در افزونه ← تب «ایمیل موقت» ← چیپ «جیمیل من (الیاس)» ← دکمهٔ **«اتصال فوری (۱ کلیک — بدون گوگل‌کلود)»**.

- شرط تنها: در همین مرورگر داخل **Gmail** لاگین باشی.
- اگر پیام **401** دیدی: کادر «رمز برنامه (App Password)» خودکار باز می‌شود — یک رمز ۱۶ حرفی از **myaccount.google.com/apppasswords** بساز (تأیید دومرحله‌ای باید روشن باشد)، ایمیل و رمز را وارد کن و «اتصال با رمز برنامه» را بزن. این روش هم **بدون Google Cloud** است و رمز فقط روی مرورگر خودت ذخیره می‌شود.
- محدودیت‌ها: فقط نامه‌های **ناخواندهٔ اینباکس** دیده می‌شوند، متن نامه به‌صورت خلاصه (snippet) است، همهٔ الیاس‌ها صندوق مشترک دارند و اعلان دسکتاپ فقط از صندوق اول جیمیل ارسال می‌شود.
- اگر حالت کامل (بدون محدودیت، با فیلتر دقیق `deliveredto:` برای هر الیاس) را خواستی، مراحل Client ID زیر را انجام بده.

---

## روش کامل — چرا باید Client ID بسازم؟

افزونه برای خواندن نامه‌ها باید از **Gmail API رسمی گوگل** استفاده کند. گوگل اجازه نمی‌دهد
افزونه‌های عمومی از جیمیل همهٔ کاربران بخوانند؛ بنابراین هر کاربر یک «کلید اتصال» شخصی
(Client ID) در حساب گوگل خودش می‌سازد. با این روش:

- توکن فقط روی مرورگر خودت ذخیره می‌شود (هیچ سروری در میان نیست)
- دسترسی افزونه فقط **خواندن** است (`gmail.readonly`) — هیچ ایمیلی ارسال یا حذف نمی‌شود

---

## قدم‌به‌قدم

### قدم ۱ — ساخت پروژه در Google Cloud

1. به آدرس زیر برو و با جیمیلت وارد شو:
   **https://console.cloud.google.com/projectcreate**
2. یک نام دلخواه بگذار (مثلاً `my-mail-plugin`) و **Create** را بزن.

### قدم ۲ — فعال‌سازی Gmail API

1. به آدرس زیر برو (همان پروژه انتخاب‌شده باشد):
   **https://console.cloud.google.com/apis/library/gmail.googleapis.com**
2. دکمهٔ **Enable** را بزن.

### قدم ۳ — تنظیم OAuth Consent Screen

1. از منوی کنار (یا جست‌وجوی بالای کنسول) **OAuth consent screen** را باز کن.
2. User Type را **External** بگذار و **Create** بزن.
3. فقط نام App را بنویس (مثلاً `MyMail`) و ایمیل‌های Support/Developer را خودت بگذار؛ بقیه را Next بزن تا تمام شود.
4. در بخش **Test users** روی **Add users** بزن و **ایمیل جیمیل خودت** را اضافه کن. (مهم!)
5. نیازی به افزودن Scope دستی نیست — هنگام ورود، افزونه فقط `gmail.readonly` را می‌خواهد.

> نکته: تا وقتی پروژه در حالت Testing است، فقط کاربرانی که به‌عنوان Test user اضافه شده‌اند (یعنی خودت) می‌توانند وصل شوند — برای استفادهٔ شخصی همین عالی است.

### قدم ۴ — ساخت OAuth Client ID

1. به **Credentials → Create Credentials → OAuth client ID** برو.
2. Application type را بگذار **Chrome Extension** (پیشنهادی).
3. در فیلد **Application ID**، این مقدار را وارد کن (از ویزارد داخل افزونه کپی کن):
   - افزونه را باز کن → تب «ایمیل موقت» → چیپ «جیمیل من (الیاس)» → «اتصال جیمیل من (یک‌بار)»
   - در ویزارد، **Extension ID** با دکمهٔ کپی در دسترس است.
4. **Create** بزن و **Client ID** ساخته‌شده را کپی کن.

<details>
<summary>اگر به‌جای Chrome Extension نوع Web application ساختی</summary>

به‌جای Application ID باید **Redirect URI** را اضافه کنی:

```
https://<EXTENSION-ID>.chromiumapp.org/
```

که `<EXTENSION-ID>` همان شناسه‌ای است که ویزارد افزونه نشان می‌دهد (کپی با یک دکمه).
هر دو نوع کار می‌کنند؛ Chrome Extension ساده‌تر است.
</details>

### قدم ۵ — اتصال در افزونه

1. در ویزارد افزونه، **Client ID** را در کادر آخر بچسبان.
2. دکمهٔ **«اتصال و انتخاب حساب گوگل»** را بزن.
3. پنجرهٔ گوگل باز می‌شود؛ حساب جیمیلت را انتخاب و **Allow** بزن.
4. تمام! حالا می‌توانی الیاس بسازی.

## استفادهٔ روزمره

1. تب **ایمیل موقت** ← چیپ **«جیمیل من (الیاس)»**
2. در کادر الیاس، نام دلخواه بنویس: مثلاً `netflix`
3. دکمهٔ **«ساخت الیاس جیمیل»** ← آدرس `you+netflix@gmail.com` ساخته و کپی می‌شود
4. آن را در فرم ثبت‌نام سایت بگذار؛ وقتی ایمیل رسید، **OTP همان‌جا ظاهر و با یک کلیک درج می‌شود**
5. نوتیف دسکتاپ برای پیام و کد تأیید هم فعال است (حتی وقتی پنجرهٔ افزونه بسته است)

هر الیاس یک کارت مستقل در لیست صندوق‌ها و جست‌وجوی سریع می‌شود؛ برچسب، پین و مرتب‌سازی روی آن‌ها کار می‌کند.

## سؤالات پرتکرار

**آیا گوگل الیاس را در اینباکس جدا نشان می‌دهد؟**
نامه‌ها به همان اینباکس اصلی می‌آیند، اما افزونه فقط نامه‌های هر الیاس را فیلتر و نمایش می‌دهد؛ اگر بخواهی می‌توانی در جیمیل هم فیلتر `to:you+netflix@gmail.com` بسازی.

**اگر Client ID را جایی استفاده کنم که نباید؟**
توکن فقط در مرورگر خودت است و سطح دسترسی فقط خواندن؛ در بدترین حالت Client ID را در کنسول گوگل Delete می‌کنی.

**چرا بعضی سایت‌ها الیاس را نرمال‌سازی می‌کنند؟**
اقلیتی از سایت‌ها علامت `+` و بعدش را حذف می‌کنند و حساب تکراری می‌شمارند. برای این سایت‌ها از ایمیل موقتی با دامنه‌های متنوع استفاده کن، یا بعداً «دامنهٔ اختصاصی» را اضافه کنیم.

**اتصال به‌هم خورد / توکن منقضی شد؟**
دکمهٔ «اتصال جیمیل من (یک‌بار)» را دوباره بزن. صندوق‌های الیاسِ ساخته‌شده حفظ می‌شوند.

**حذف اتصال؟**
روی دکمهٔ ✕ کنار ایمیل متصل بزن. هیچ نامه‌ای حذف نمی‌شود؛ فقط دسترسی افزونه قطع می‌شود.
