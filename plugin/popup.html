نشست این تب: نشست جدید (ذخیره‌نشده)
هر تب کوکی و حافظه کاملاً جداگانه دارد تا همزمان با چند اکانت کار کنید.
هنوز اکانتی برای این سایت ذخیره نشده است
  1. در صورت نیاز از تب «ایمیل موقت» یک ایمیل بسازید و کد تأیید را بگیرید.
  2. پس از ورود به اکانت در سایت، «ذخیره اکانت فعلی» را بزنید.
  3. با «نشست جدید» اکانت‌های بعدی را بسازید و همزمان در تب‌های جدا باز کنید!

اگر خطای Error 400: redirect_uri_mismatch دیدی:
  1. کنسول گوگل → APIs & Services → Credentials → روی همان OAuth client کلیک کن.
  2. نوع Chrome extension: فیلد Application ID باید دقیقاً برابر «Extension ID» همین ویزارد باشد (کپی با دکمهٔ همین مرحله).
  3. نوع Web application: در Authorized redirect URIs دقیقاً همان «Redirect URI» همین ویزارد را اضافه کن — با اسلش انتهایی /.
  4. نوع Desktop app کار نمی‌کند؛ یک کلاینت جدید از نوع Chrome extension بساز.
  5. Save بزن، ۱ تا ۲ دقیقه صبر کن، پنجرهٔ قبلی گوگل را ببند و دوباره «اتصال» را بزن.
اگر خطای Error 403: access_denied دیدی:
  1. یعنی جیمیلت هنوز «Test user» پروژه نیست. کنسول گوگل → APIs & Services → OAuth consent screen (یا Google Auth Platform → Audience).
  2. بخش Test users → Add Users → ایمیلِ همان جیمیلی که در پنجرهٔ ورود انتخاب می‌کنی را اضافه کن → Save.
  3. پنجرهٔ خطا را ببند و دوباره «اتصال» را بزن.
  4. اگر صفحهٔ «Google hasn't verified this app» آمد: Advanced → Go to app (unsafe) → Allow.
